# Oyu Cargo — Илгээмж хянах систем

## Юу хийгддэг вэ?
- **/public/index.html** — Нийтийн вэбсайт. Хэрэглэгч утасны дугаараа оруулбал бараагаа хянана.
- **/admin/index.html** — Админ панель. Нэвтэрч орж бараа бүртгэх, засах, устгах.
- **server.js** — Backend (Node.js + Express + SQLite). Бүх өгөгдлийг `data/oyucargo.db` файлд хадгална.

## Хэрхэн ажиллуулах вэ?

1. Node.js суулгасан байх ёстой (nodejs.org)
2. Терминал нээгээд энэ хавтас руу ор:
   ```
   cd oyu-cargo
   npm install
   npm start
   ```
3. Хөтчөөр нээ:
   - Нийтийн сайт: http://localhost:3000
   - Админ панель: http://localhost:3000/admin

## Анхны админ нэвтрэх мэдээлэл
- Нэвтрэх нэр: **admin**
- Нууц үг: **oyu2026**

⚠️ Эхний удаа нэвтэрсний дараа "Нууц үг солих" товчоор нууц үгээ солиорой.

## Ажиллах логик
1. Админ хэрэглэгч `/admin` хуудсанд нэвтэрч, хэрэглэгчийн **утасны дугаар** + барааны нэр/код/төлөв оруулж бүртгэнэ.
2. Нийтийн хуудсан дээрх "Илгээмж шалгах" цонхонд хэрэглэгч утасны дугаараа бичихэд, тухайн дугаараар бүртгэгдсэн бараа(нууд) автоматаар гарч ирнэ.
3. Нэг утасны дугаараар олон бараа бүртгэх боломжтой (жишээ нь хэд хэдэн захиалгатай бол бүгд гарч ирнэ).

## Логог солих
`public/index.html` болон `admin/index.html` дотор `logo-circle.png` файлыг ашигладаг — таны upload хийсэн зурган дээрх логог PNG болгож энэ нэрээр `public/` хавтас руу хийвэл автоматаар харагдана.

## Сервер хостлох
Локал компьютерт туршсаны дараа жинхэнэ домэйн дээр байршуулахдаа Render, Railway, эсвэл VPS (жишээ: DigitalOcean) ашиглаж болно — надад хэлээрэй, тухайн үйлчилгээнд тохируулж deploy хийх зааврыг гаргаж өгье.
